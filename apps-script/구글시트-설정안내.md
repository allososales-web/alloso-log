# 구글 시트 연동 설정 안내 (사업부 담당자용)

이 문서는 **딱 한 번**만 하면 됩니다. 완료하면 모든 매장의 기록이
구글 시트 한 곳에 자동으로 모입니다. 매장 매니저는 아무 설정도 하지 않습니다.

소요 시간: 약 10분. 필요한 것: **구글 계정(Workspace) 1개**.

---

## 1단계. 구글 시트 만들기

1. [sheets.google.com](https://sheets.google.com) 접속 → **빈 스프레드시트** 생성
2. 이름을 알아보기 쉽게 변경 (예: `기록의 창 - 매장 기록`)
3. 시트는 비워두어도 됩니다. (코드가 자동으로 **분기별 시트**와 헤더를 만듭니다.)

---

## 2단계. Apps Script 코드 붙여넣기

1. 방금 만든 시트 상단 메뉴에서 **확장 프로그램 → Apps Script** 클릭
2. 기본으로 열린 `Code.gs` 내용을 **모두 지우고**,
   이 폴더의 **`Code.gs` 파일 내용 전체**를 복사해서 붙여넣기
3. 저장 (💾 또는 Ctrl+S)

---

## 3단계. 웹앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포** 클릭
2. 톱니바퀴(유형 선택) → **웹 앱** 선택
3. 설정:
   - **설명**: 아무거나 (예: `기록의 창 v1`)
   - **실행 계정**: `나`
   - **액세스 권한이 있는 사용자**: **`모든 사용자`**
     - ⚠️ 이 값이 중요합니다. 매장 매니저가 로그인 없이 저장하려면 "모든 사용자"여야 합니다.
4. **배포** 클릭
5. 처음이면 권한 승인 창이 뜹니다 → 본인 계정 선택 →
   "안전하지 않음" 경고가 보이면 **고급 → (프로젝트 이름)으로 이동 → 허용**
   (본인이 만든 스크립트라 안전합니다.)
6. 배포가 끝나면 **웹 앱 URL**이 나옵니다.
   `https://script.google.com/macros/s/AKfy....../exec` 형태입니다.
   이 주소를 복사하세요.

---

## 4단계. 사이트에 주소 연결하기

연결 방법은 두 가지 중 하나를 선택하세요.

### 방법 A. config.js 에 넣기 (모두에게 영구 적용, 권장)

프로젝트의 `config.js` 파일을 열어 `backendUrl` 값을 방금 복사한 주소로 바꿉니다.

```js
backendUrl: "https://script.google.com/macros/s/AKfy....../exec"
```

저장 후 GitHub에 다시 올리면(배포하면), 모든 사람이 구글 시트로 저장/조회하게 됩니다.

### 방법 B. 브라우저에서 임시로 넣기 (테스트용)

사이트를 열어둔 상태에서 브라우저 개발자도구(F12) 콘솔에 아래를 입력:

```js
localStorage.setItem("girock_backend_url", "여기에_웹앱_URL_붙여넣기");
```

이 방법은 그 브라우저에서만 적용됩니다.

---

## 5단계. 확인

1. 사이트의 **매장 기록하기**에서 한 건 저장
2. 구글 시트에 **분기 시트**(예: `records_2026Q4`)가 생기고 한 줄이 쌓이면 성공
3. 사이트의 **사업부 보기**에서 그 기록이 보이면 완료

---

## ★ 분기별 아카이빙 (자동)

데이터가 많이 쌓여도 사업부 페이지가 느려지지 않도록, 기록을 **분기별 시트로 자동
분리**합니다.

- 기록은 작성일이 속한 분기 시트에 자동 저장됩니다.
  - 1~3월 → `records_YYYYQ1`
  - 4~6월 → `records_YYYYQ2`
  - 7~9월 → `records_YYYYQ3`
  - 10~12월 → `records_YYYYQ4`
  - 예) 2026년 11월 기록 → `records_2026Q4` 시트
- 시트는 **처음 그 분기에 기록이 들어올 때 자동 생성**됩니다. 미리 만들 필요 없습니다.
- **사업부 보기**는 접속 시 **현재 분기 시트 하나만** 불러옵니다. 그래서 과거
  데이터가 아무리 많아도 로딩 시간이 일정합니다.
- 과거 분기를 보려면 사업부 페이지 상단의 **분기 선택 드롭다운**에서 원하는 분기를
  고르면 그 분기만 추가로 불러옵니다.

### 기존 데이터 옮기기 (한 번만)

이전 버전에서 쓰던 단일 `records` 시트에 데이터가 있다면, 분기 시트로 한 번에
나눠 옮길 수 있습니다.

1. **확장 프로그램 → Apps Script** 열기
2. 함수 선택 드롭다운에서 **`migrateToQuarters`** 선택 → **실행**
3. 권한 승인 창이 뜨면 허용
4. 실행 로그(**보기 → 로그**)에 `마이그레이션 완료 → 2026Q3: 12건, 2026Q4: 30건 …`
   처럼 요약이 나옵니다.
5. 분기 시트들에 데이터가 잘 들어갔는지 확인한 뒤, 기존 `records` 시트는
   **수동으로 삭제**하세요. (코드는 원본을 지우지 않습니다.)

> 참고: `migrateToQuarters`는 원본을 복사만 하므로 여러 번 실행하면 중복될 수
> 있습니다. **한 번만** 실행하세요.

## 자주 묻는 질문

**Q. 매장도 가입해야 하나요?**
아니요. 매장은 사이트 링크로 접속해서 매장 선택 후 기록만 하면 됩니다.

**Q. 코드를 수정하면 다시 배포해야 하나요?**
네. `Code.gs`를 바꾸면 **배포 → 배포 관리 → (연필 아이콘) → 버전: 새 버전 → 배포**로
기존 URL을 유지한 채 업데이트할 수 있습니다. (URL은 그대로 유지됩니다.)

**Q. 데이터는 어디에 저장되나요?**
구글 시트에 분기별 시트(`records_YYYYQn`)로 텍스트만 저장됩니다. 음성 파일은
저장하지 않습니다.

**Q. 분기가 바뀌면 제가 시트를 만들어야 하나요?**
아니요. 새 분기의 첫 기록이 들어오는 순간 시트가 자동으로 생성됩니다.

**Q. 1년치나 전체를 한 번에 보고 싶어요.**
사업부 페이지 분기 드롭다운에서 분기를 바꿔가며 볼 수 있습니다. 전체를 합쳐 보려면
웹앱 URL 뒤에 `?action=list&quarter=all` 을 붙여 호출할 수 있지만, 데이터가 많으면
느릴 수 있어 일상 조회에는 분기별 보기를 권장합니다.

**Q. AI 요약 키(Gemini)는 여기서 넣나요?**
아니요. Gemini 키는 **사업부 보기 페이지 화면**에서 직접 입력합니다.
이 구글 시트 설정과는 별개입니다.
