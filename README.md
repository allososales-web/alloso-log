# 기록의 창

매장 매니저가 **음성으로 하루를 기록**하고, 사업부가 **한눈에 모아 보고 AI로 요약**하는 통합 사이트입니다.

- 매장: 링크 접속 → 매장/익명 선택 → 말하면 글자로 변환 → 저장 (가입·로그인 없음)
- 사업부: 모든 기록을 모아 보고, 자동 요약 + Gemini AI 요약/대처방안 확인
- 저장: 구글 시트 한 곳으로 통합 (음성 파일은 저장하지 않고 텍스트만 보관)
- 호스팅: GitHub Pages (서버 불필요, 무료)

---

## 화면 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 첫 화면. 매장용 / 사업부용 선택 |
| `write.html` | 매장 기록 입력 (음성인식 → 텍스트 → 저장) |
| `dashboard.html` | 사업부 보기 (현황·자동 요약·AI 요약·기록 목록) |
| `config.js` | **매장 목록**과 **구글 시트 URL** 설정 |
| `storage.js` | 저장/조회 (시트 또는 localStorage 자동 전환) |
| `summary.js` | 키 없이 즉시 계산되는 규칙 기반 요약 |
| `gemini.js` | Gemini API 호출 (사업부 페이지에서 키 입력) |
| `style.css` | 공통 디자인 |
| `apps-script/` | 구글 시트 백엔드 코드 + 설정 안내 |

## 시작하기 (3단계)

### 1) 지금 바로 테스트 (설정 0)

구글 시트를 연결하지 않아도 동작합니다. 이때 기록은 **그 브라우저에만** 저장됩니다.

- `index.html`을 브라우저로 열기
  (음성인식은 **크롬**에서 가장 잘 동작하며, 마이크 권한 허용이 필요합니다.)

> 로컬 파일(`file://`)로 열면 일부 브라우저에서 마이크/기능이 제한될 수 있습니다.
> 아래처럼 간단한 로컬 서버로 여는 것을 권장합니다.
>
> ```powershell
> # 파이썬이 있다면 프로젝트 폴더에서
> python -m http.server 5500
> # 그런 다음 브라우저에서 http://localhost:5500 접속
> ```

### 2) 매장 목록 수정

`config.js`의 `stores` 배열에 실제 매장명을 넣으세요.

```js
stores: ["강남점", "홍대점", "부산서면점"]
```

### 3) 구글 시트 통합 (모든 매장 기록을 한곳에)

`apps-script/구글시트-설정안내.md`를 따라 10분이면 끝납니다.
배포 후 나온 웹앱 URL을 `config.js`의 `backendUrl`에 넣으면 통합 완료입니다.

```js
backendUrl: "https://script.google.com/macros/s/AKfy....../exec"
```

## 주요 기능

**매장 기록 (write.html)**
- 오늘 날짜 자동 표시, 글자 수 실시간 표시
- 음성인식(크롬 권장) → 텍스트 변환, 직접 수정 가능
- 마지막에 고른 매장/기록자 기억 (반복 입력 편의)
- 저장 연타 방지, 너무 짧은 내용 방지
- **오프라인/서버 실패 시 기기에 안전 보관 후, 다음 저장 때 자동 재전송** (데이터 유실 방지)

**사업부 보기 (dashboard.html)**
- 진입 즉시 현황 통계 + 규칙 기반 자동 요약 (AI 없이)
- 매장별 요약 카드 (건수·주의 건수·미리보기, 클릭하면 해당 매장만 필터)
- 매장/날짜/내용 검색 필터, 필터 초기화
- CSV 내보내기 (엑셀에서 한글 정상 표시)
- Gemini AI 요약: 들어오면 자동 실행, 결과 복사, 실패 시 다시 시도
- 키 없이 쓰려면 "Gemini용 프롬프트 복사" 제공
- 선택적 접근 암호(PIN)로 사업부 페이지 보호 가능
- (로컬 테스트 모드에서는 기록 개별/전체 삭제 가능)

## AI 요약 (Gemini) 사용법

사업부 보기 페이지에서 직접 **Gemini API 키**를 입력하면, 들어올 때마다 자동으로
AI 요약과 추천 대처방안이 표시됩니다.

1. [Google AI Studio](https://aistudio.google.com) 접속 (Workspace 계정) → **Get API key** → 키 발급
2. `dashboard.html`의 **AI 상세 요약** 영역에 키 붙여넣기 → **키 저장 & 요약 실행**
3. 키는 그 브라우저(localStorage)에만 저장됩니다. 매장 매니저에게는 노출되지 않습니다.

> 키가 없어도 "자동 요약"(규칙 기반)은 항상 표시됩니다.
> 키 없이 쓰고 싶으면 **Gemini용 프롬프트 복사** 버튼으로 복사해 Gemini 앱에 붙여넣어도 됩니다.

모델명은 입력란에서 바꿀 수 있습니다. 기본값은 `gemini-2.0-flash` 입니다.

## 사업부 페이지 접근 암호 (선택)

사업부 보기를 아무나 열지 못하게 하려면 `config.js`에서 PIN을 설정하세요.
매장 기록 페이지는 암호 없이 항상 열립니다.

```js
dashboardPin: "1234"   // 비워두면 누구나 접근 가능
```

> 이 PIN은 간단한 화면 보호용입니다. 강한 보안이 필요하면 구글 시트 공유 범위와
> 배포 저장소 접근 권한으로 관리하세요.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소에 올립니다.

   ```powershell
   git init
   git add .
   git commit -m "기록의 창 초기 버전"
   git branch -M main
   git remote add origin https://github.com/<사용자>/<저장소>.git
   git push -u origin main
   ```

2. GitHub 저장소 → **Settings → Pages**
3. **Build and deployment**에서 Source를 **Deploy from a branch**,
   Branch를 **main / (root)** 로 설정하고 저장
4. 잠시 후 `https://<사용자>.github.io/<저장소>/` 주소로 접속하면 배포 완료

> 배포 주소를 매장 매니저들에게 공유하면 됩니다. 매장은 가입/설정이 필요 없습니다.

## 개인정보 / 보안 메모

- 음성 파일은 저장하지 않으며, 변환된 **텍스트만** 보관합니다.
- 기록자는 **익명**으로만 선택합니다.
- Gemini 키는 사업부 담당자 브라우저에만 저장되고, 호출은 브라우저에서 Google로 직접 전송됩니다.
- 사업부 페이지에 접근 제한이 필요하면, 운영 단계에서 간단한 접근 암호를 추가할 수 있습니다.
